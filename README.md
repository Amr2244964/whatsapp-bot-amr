# بوت واتساب للرد التلقائي (برمجة عمرو)

هذا البوت مصمم للرد التلقائي على الرسائل الواردة في واتساب لمساعدة الدفعة وتسهيل الأمور عليهم.

## المميزات:
- **الرد الأول:** يرحب بالمستخدم ويعرف بنفسه وبالمبرمج (عمرو).
- **الرد الثاني:** يوضح الخدمات التي يمكن تقديمها (مصادر دراسية، استفسارات، إلخ).
- **حفظ الجلسة:** يستخدم `LocalAuth` لحفظ بيانات تسجيل الدخول، مما يعني أنك ستمسح رمز QR مرة واحدة فقط.

## متطلبات التشغيل:
1. تثبيت **Node.js** (الإصدار 16 أو أحدث) من الموقع الرسمي: [nodejs.org](https://nodejs.org/)
2. متصفح **Google Chrome** أو **Chromium**.

## خطوات التشغيل على جهازك:
1. قم بفك ضغط الملف الذي أرسلته لك.
2. افتح نافذة الأوامر (Terminal أو CMD) داخل مجلد البوت.
3. قم بتثبيت المكتبات اللازمة بكتابة الأمر التالي:
   ```bash
   npm install
   ```
4. قم بتشغيل البوت بكتابة الأمر التالي:
   ```bash
   node index.js
   ```
5. سيظهر لك رمز QR في نافذة الأوامر، قم بمسحه من تطبيق واتساب (الأجهزة المرتبطة > ربط جهاز).

## كيف تجعل البوت يعمل 24/7؟
لجعل البوت يعمل بشكل دائم ومستقل حتى لو أغلقت جهازك، يمكنك استخدام إحدى الطرق التالية:
1. **استخدام خادم (VPS):** يمكنك استئجار خادم صغير (مثل DigitalOcean أو Linode) وتشغيل البوت عليه باستخدام أداة `pm2` لضمان عدم توقفه.
2. **منصات الاستضافة المجانية:** يمكنك تجربة منصات مثل **Render** أو **Railway** (قد تحتاج لبعض الإعدادات الإضافية لمتصفح Puppeteer).
3. **جهاز قديم:** إذا كان لديك لابتوب قديم لا تستخدمه، يمكنك تركه يعمل وتشغيل البوت عليه بشكل دائم.
